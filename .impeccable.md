# Design Context — Argus

## Target audience
- Developers, solo founders, and "vibe coders" who run products on MongoDB and have no data team.
- Hackathon judges (MongoDB engineers — Daoud Farooqi, Gaurab Aryal) who will read the code, poke the hosted URL, and try to break the read-only guarantees.

## Use cases
- Paste a MongoDB connection string → agent samples the schema → proposes insights → generative dashboard of insight cards (funnel, cohort, RFM, attribution, anomaly) materializes in 2–3 minutes.
- Ask the agent anything in chat; it renders cards, not just text. Asking it to mutate data triggers a calm refusal explaining three-layer write protection.
- 3-minute demo video and 30-second README skim are first-class use cases: every surface must read well in a screenshot.

## Brand personality / tone
**"The Observatory"** — a calm, precise, editorial scientific instrument. Argus watches; it doesn't shout.
- Observational, not interactive-flashy. The data is the spectacle; the chrome stays quiet.
- Calm, not alarming. Anomalies are flagged matter-of-factly.
- Precise: numbers in JetBrains Mono with tabular-nums; MQL shown honestly; honest claims (2–3 min, not 60 s).
- Dark mode default (developers live in terminals); warm beige light mode.

## Visual rules
- Tokens only: `--argus-*` from `frontend/app/globals.css`. One accent (teal). 1px borders over shadows.
- Type: Syne display, DM Sans body, JetBrains Mono data.
- Forbidden: purple→blue gradients, gradient text, gradient icon tiles, glow shadows as decoration, glassmorphism, emoji icons, infinite animations, centered generic SaaS hero.
- Motion: one staggered load reveal per route, 200–300ms ease-out, `prefers-reduced-motion` respected.

## Visual references
Linear, Vercel dashboard, MongoDB Compass dark mode. NOT Tableau, NOT ChatGPT.
